4. TEXTOS E DADOS DOS PERSONAGENS
-----------------------------------
ANTES:
  Escritos direto dentro de cada arquivo .html (nome, idade, posto,
  status, curiosidades, tudo em texto fixo no HTML).

DEPOIS:
  Guardados no banco de dados SQLite (arquivo db/hashiras.db), em
  duas tabelas:

  - personagens (id, nome, idade, posto, status, cor_tema, imagem_perfil)
  - curiosidades (id, personagem_id, imagem, texto, ordem)

  Cada curiosidade está ligada a um personagem pelo campo
  "personagem_id" (relação 1 personagem : N curiosidades).


5. BACKEND E API (NOVO — NÃO EXISTIA ANTES)
----------------------------------------------
Criado um servidor com Node.js + Express (arquivo server.js) que:

  a) Serve os arquivos do site (pasta public/)
  b) Expõe uma API que devolve os dados do banco em JSON:

     GET /api/personagens
       -> devolve a lista de todos os personagens

     GET /api/personagens/:id
       -> devolve um personagem específico, já com suas curiosidades
          (ex: /api/personagens/sanemi)

  O front-end (o que roda no navegador) não lê o banco diretamente —
  ele pede os dados pra essa API usando fetch(), e monta a página
  com o que recebe de volta.


6. JAVASCRIPT DO FRONT-END (NOVO)
------------------------------------
  - public/js/index.js
      Busca a lista de personagens em /api/personagens e cria um
      "card" na tela pra cada um, com link pra página de detalhe.

  - public/js/personagem.js
      Lê o "?id=" da URL (ex: personagem.html?id=uzui), busca esse
      personagem em /api/personagens/uzui e monta a página com nome,
      idade, status, cor do tema e todas as curiosidades.

8. PROBLEMAS RESOLVIDOS DURANTE A INSTALAÇÃO
------------------------------------------------
  - "db.exec is not a function": o pacote better-sqlite3 não tinha sido
    instalado corretamente. Resolvido reinstalando as dependências
    (apagando node_modules e package-lock.json e rodando npm install
    de novo).
  - "localhost:3000 abrindo o Grafana": outro programa (Grafana) já
    estava usando a porta 3000 no computador. Resolvido trocando a
    porta do projeto para 3001 no server.js.
  - "Conexão recusada mesmo com o servidor rodando": o terminal onde
    o npm start tinha sido rodado já tinha voltado ao prompt normal,
    ou seja, o servidor não estava mais ativo. Resolvido rodando
    npm start de novo e deixando o terminal aberto.
